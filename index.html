Repository map

What is here

Runtime app

apps/nppm contains the x_mainmoil C++ target, recipe resolution, media loading, and UI loop.

Control panel

tools/nppm_control_server.py provides recipe selection, demo toggles, countdowns, and editor controls.

Recipe formats

Current runtime recipes are .cast and .yaml; .script remains as a legacy migration input.

Local runbook

Quick start

Build
cmake -S . -B build -DOpenCV_DIR=/home/cj/cv-2026/lib/cmake/opencv4
cmake --build build -j2
Run desktop app
DISPLAY=:0 ./build/apps/nppm/x_mainmoil
Run browser panel
python3 tools/nppm_control_server.py

http://127.0.0.1:8080

Runtime flow

How a demo run is selected

  1. 1

    Resolve metadata root

    Use CJ_NPPM_META, repo-local metadata, or the configured Dropbox-backed .nppm-meta fallback.

  2. 2

    Choose active recipe

    Prefer defaultS/active_recipes.yaml; fall back to compatibility files when needed.

  3. 3

    Launch media projection

    x_mainmoil loads the selected cast or YAML recipe and renders the configured media source.
